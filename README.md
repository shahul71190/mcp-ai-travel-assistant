
# 🌍 MCP AI Travel Assistant

An AI-powered travel assistant built with **n8n, Model Context Protocol (MCP), and Groq LLM**, designed to connect AI with external travel-related APIs.

## ✨ Overview

This project demonstrates how an AI assistant can use external tools and API integrations to help users explore travel information.

## 🚀 Features

- 🌦️ Weather information
- 🏨 Hotel information
- 🍽️ Restaurant discovery
- 📍 Tourist attractions
- 💱 Currency exchange rates
- 🤖 AI-powered interaction using Groq LLM
- 🔌 MCP-based tool integration
- ⚙️ Workflow orchestration with n8n

## 🧰 Tech Stack

| Technology | Purpose |
|---|---|
| n8n | Workflow automation |
| MCP | AI-to-tool integration |
| Groq LLM | Language model |
| External APIs | Travel information |
| JSON | Structured data exchange |

## 🔄 How It Works

1. A user submits a travel-related request.
2. The AI assistant interprets the request.
3. The workflow connects to relevant tools or external APIs.
4. Retrieved information is used to formulate a response.
5. The assistant presents relevant travel information to the user.

## 🎯 Use Cases

- Exploring travel destinations
- Checking weather conditions
- Finding hotels and restaurants
- Discovering local attractions
- Checking currency exchange rates
